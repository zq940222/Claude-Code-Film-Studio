# 声音设计规范（插件内置）

## 运行时适配（跨 Agent 兼容）

- 本技能是**纯知识规范**（无流程、无 subagent 调度、无门禁）：任何运行时直接把本文当标准使用即可
- **无 Skill 工具的运行时**（Codex CLI / OpenClaw 等）：直接读取本文件（插件 `skills/sound-design/SKILL.md`）
- 本文给的是**判断标准与目标值**，不是可执行流程；实际操作在 `/music`（配乐师）与 `/finalcut`（精剪师）里进行

## 定位：本工作台的声音是"三层轨"，不是"配个音乐"

| 轨 | 来源 | 谁负责 | 铁律 |
|---|---|---|---|
| **原声轨** | 即梦生成的视频自带（台词 + 环境音 + 动作音） | 视频生成师保住不丢 | **不重配、不替换**——重配等于丢掉口型对齐 |
| **BGM 轨** | Suno 生成（`/music`） | 配乐师产出、精剪师对位 | 独立素材，**不混进粗剪** |
| **人声补轨** | 剪映「文本朗读」生成的内心独白/旁白 | 精剪师排位、用户在剪映里点 | 只补 `【独白】`/`【旁白】`，**对白永远用原声** |

三层各司其职。绝大多数"声音出问题"都是这三层的**分工被越界**导致的：拿 BGM 盖对白、
用 TTS 重配对白、把 BGM 混进粗剪导致回炉时音画一起废。

## 响度与动态

短视频平台普遍会做响度归一化（业界常见目标在 **-14 LUFS 上下**），所以：

- **别一味推大**。推过头会被平台压回，压回时动态一起被压扁，结果是"响但闷"
- 整片综合响度对齐到 **-14 LUFS 附近**，真峰值留 **-1 dBTP** 余量防削波
- **对白是响度基准**，不是 BGM。先把对白调到舒服的位置，其余音轨围着它排
- 电影短片可以放宽动态（安静段真的安静）；短剧/段子在手机小喇叭上听，动态范围压窄一点更稳

自查（ffmpeg 两平台通用，只测不改）：

```bash
ffmpeg -i "05-final/剧名-ep01.mp4" -af loudnorm=print_format=summary -f null -
```

看 `Input Integrated`（综合响度）与 `Input True Peak`。偏离目标超过 2 LU 就在精剪里调总线，
**别去逐镜改原声**——逐镜调音量是音量跳变的头号来源。

## Ducking：BGM 给对白让路

对白段把 BGM 压下去，是"听得清"最有效的一招：

- 压制量 **6–10 dB**（对白密集的短剧取上限，电影短片取下限）
- **起降要快、恢复要慢**：对白进来时立刻压（几十毫秒），说完后缓慢抬回（300–500 ms）。
  恢复太快会有"呼吸感"（BGM 一鼓一鼓）
- 剪映：给 BGM 轨用"自动踩低/闪避"类功能，或手动打关键帧；Resolve：BGM 轨挂压缩器走侧链，或手动关键帧
- **手动关键帧反而更可控**：一集也就十几处对白，画关键帧比调参数快

## 音效时机：声音要早于画面

- **音先于画 1–3 帧**：切镜的冲击音、转场的 whoosh 都提前一点点，听感上才"跟得上"；
  卡在同一帧上反而显得慢半拍
- **riser 提前 1–2 秒**起，在反转点/钩子点落下——riser 的作用是"预告"，落在事后就没用了
- **一个梗/一个反转只配一个重音**。段子里最容易犯的错是每句都加音效，结果重点全被淹没

## 音桥：让硬切不生硬（最省力的一招）

声音跨过切点，画面切了声音没切（或反过来）：

- **L-cut（声音后走）**：上一镜的声音延续到下一镜画面里——适合情绪延续、对话戏
- **J-cut（声音先到）**：下一镜的声音提前进来——适合空间转换、悬念前置

这两招不需要任何素材，只需要在时间线上把音频轨的边界拖出画面边界。
**分镜「衔接」列写了"无缝衔接"/"动接动"的地方，优先用音桥而不是加转场特效。**

## 即梦原声的三个已知坑

1. **镜间音量不齐**：不同镜头的原声电平可能差几个 dB。精剪第一步就是把所有镜头原声轨拉齐，
   再排 BGM——顺序反了会一直在"补丁上打补丁"
2. **底噪不一致**：多镜连播时底噪跳变很明显。BGM 铺满全片是最省事的遮盖手段（这也是 BGM 的实用价值之一）
3. **`multiframe2video` 静音**：智能多帧的镜头**天生没有音轨**，这是正常的，
   **绝不因为缺音轨去重生成烧积分**。在精剪里给它补环境音/BGM 即可

## 四种形态的声音法则

| 形态 | 声音重心 | BGM 密度 | 特征做法 |
|---|---|---|---|
| `short-drama` 短剧 | **对白清晰度压倒一切** | 铺满，但常压在低位 | 反转点重音 + riser；BGM 让位幅度取上限 |
| `short-film` 电影短片 | **环境音与留白** | 稀疏，敢留无 BGM 段 | 动态范围大；关键处靠"突然安静"制造张力 |
| `anime` 动漫番剧 | **音效夸张 + BGM 主导情绪** | 铺满且情绪明确 | 定格瞬间配重音；情绪峰值让 BGM 走到前景 |
| `sketch` 创意段子 | **音效即包袱** | 中等，梗点前常掐断 | 梗点前留 comic pause（半秒静音），反转瞬间给音效标点 |

## 商单条的声音注意

- **口播词必须听得清**：口播段落把 BGM 压到最低甚至掐掉，这是合规要求不是审美选择
- 口播用即梦原声（对白轨），**不要用 TTS 重配**——重配的口播一听就假，转化率反而低
- 产品音效（开罐声、提示音之类）如 brief 有指定，按 brief 来；brief 没提就别自己加

## 交付自检

配乐师交付 `bgm-notes.md`、精剪师交付工程前，逐条过：

- [ ] 三层轨分工没有越界（没拿 TTS 重配对白、没把 BGM 混进粗剪）
- [ ] 每段 BGM 都标了**起止时间码**和**对应剧情段落**，精剪师能直接对位
- [ ] 对白段的 ducking 处理写明了（压多少、哪几处）
- [ ] 静音镜头（`multiframe2video` 或标了 `silent`）已列出并给了补音方案
- [ ] 整片响度用 ffmpeg 实测过，不是估的
- [ ] 商单条：口播段落的 BGM 处理已单独说明
