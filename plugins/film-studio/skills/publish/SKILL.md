# /publish 平台发布（含门禁④）

## 运行时适配（跨 Agent 兼容）

- **支持 subagent 的运行时**（Claude Code / Hermes Agent 等）：按下文"调度 xxx agent"正常派发子代理执行
- **不支持 subagent 的运行时**（Codex CLI / OpenClaw 等，以插件 bundle 方式安装）：正文提到"调度 X agent"时，
  改为读取插件根 `agents/<X>.md`（本技能目录上两级），以其为工作规范在当前上下文直接执行，效果等同
- **用户确认处**：有 AskUserQuestion 工具就用；没有则直接在对话中提问并等待用户回复，门禁语义不变


## 前置检查

- 成片存在（剪映导出的成片或 05-final 粗剪均可，问用户用哪个文件发布）
- 浏览器已登录目标平台创作者中心（未登录时运营 agent 会停下等用户扫码）

## 流程

1. 调度 **operator** agent 产出发布物料到 `06-publish/ep{NN}/`：
   - `copy.md`：3 个候选标题、正文、话题标签、发布时段建议、置顶评论话术
   - `cover.png`：封面图（成片抽帧 + 大字标题；剧照不够炸时走生成路径）
2. 用户选定标题和封面后，问发布方式：**立即发布 / 定时发布（要时间）/ 只出物料不发布**
3. 发布执行（半自动）：operator 用浏览器自动化上传视频、填文案、传封面
4. **门禁④**：全部填好后截图发布预览页，用 AskUserQuestion 让用户确认后才点发布。
   **商单条附加检查**（project.json 有 `sponsors.ep{NN}` 时）：确认用户已完成平台商单报备（抖音星图/B站花火，平台后台由用户本人操作）+ 文案已带广告声明——两项未确认不发布
5. 发布后截图存档，写 `publish-log.md`（时间、链接、终稿文案；商单条另记品牌名与报备方式）；多平台逐个执行，每个平台单独过门禁④

## 硬性规则

- 未经门禁④确认绝不点发布；账号登录永远由用户本人完成
- 连载剧提醒保持标题格式和封面版式的系列一致性（参考上一集的 publish-log）
- 互动钩子话术按平台切换：B站喊三连、抖音喊点赞关注，不跨平台混用
- 商单条未确认"平台报备+广告声明"不发布（门禁④扩展语义）

## 交付自检（门禁④ 之前逐条过）

发布不可撤回，判据从严：

- [ ] `copy.md` 齐：3 个候选标题、正文、话题标签、发布时段建议、置顶评论话术
- [ ] `cover.png` 存在；字在安全区内（竖屏中心偏上，别贴底被平台 UI 吃掉）；连载剧版式与上一集一致
- [ ] 互动话术按平台切了（B站三连 / 抖音点赞关注），没有跨平台混用
- [ ] 文案里没有违禁词：绝对化用语、导流外链、二维码
- [ ] 商单条：平台报备（星图/花火）与广告声明**两项都经用户确认**
- [ ] 门禁④ 获用户明确确认**之后**才点的发布（含"确认定时发布"）；`history/gates.jsonl` 追加了门禁④ 的确认行
- [ ] `publish-log.md` 记了时间、链接、终稿文案（商单条另记品牌名与报备方式）
- [ ] 降级为手动上传时：**没有**把 `publish-log.md` 记成已发布，且已把可复制的上传清单交给用户
