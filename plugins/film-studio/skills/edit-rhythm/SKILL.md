# 剪辑节奏规范（插件内置）

## 运行时适配（跨 Agent 兼容）

- 本技能是**纯知识规范**（无流程、无 subagent 调度、无门禁）：任何运行时直接把本文当标准使用即可
- **无 Skill 工具的运行时**（Codex CLI / OpenClaw 等）：直接读取本文件（插件 `skills/edit-rhythm/SKILL.md`）
- 落地在 `/storyboard`（导演定镜长与衔接）、`/edit`（粗剪看节奏）、`/finalcut`（精剪定转场）

## 前提：本工作台的节奏在**分镜阶段**就定死了

传统剪辑可以在海量素材里挑节奏。这里不行——**每个镜头都是花积分生成的，长度在提交时就固定了**。
所以：

> **节奏是导演在分镜表上设计出来的，不是剪辑师在时间线上救出来的。**

这条决定了本文的用法：主要读者是**导演**（写 `duration` 和「衔接」列时），
其次才是剪辑/精剪师（执行时）。节奏错了要回 `/storyboard` 改再重拍，不是在剪辑里硬凑。

## 平均镜长：四种形态的基准

| 形态 | 平均镜长 | 开场黄金时间 | 节奏特征 |
|---|---|---|---|
| `short-drama` 短剧 | **2–4 秒** | **黄金 3 秒**：3 秒内必须出冲突或悬念 | 高密度，反转前拉长一拍再连切 |
| `short-film` 电影短片 | **4–8 秒** | 前 15 秒建立基调即可 | 敢留白，允许长镜呼吸 |
| `anime` 动漫番剧 | **3–6 秒** | 前 5 秒定风格与情绪 | 情绪峰值处定格拉长，动作段快切 |
| `sketch` 创意段子 | **1.5–3 秒** | **黄金 1 秒**：第一帧就得有梗或反常 | 铺垫紧凑，梗点前留 pause |

**这是平均值不是上限。** 即梦单次可生成 4–15 秒，连续戏用 8–15 秒长镜 + 时间码多节拍反而更好——
一致性和原声都保住了，而"节奏快"靠的是**镜头内部的切镜**，不是把每镜都砍成 4 秒。
把每个镜头都做成 4 秒单动作短片，是本工作台最常见的节奏错误。

## 切点：在哪一帧切

- **动接动**（最常用）：上一镜的动作切到一半，下一镜接着这个动作的后半。观众的注意力被动作带着走，
  切点几乎察觉不到。分镜「衔接」列写"动接动"就是这个
- **静接静**：两个镜头都在静止状态时切，适合情绪停顿、场景转换
- **视线引导**：上一镜人物看向画外某处，下一镜给出他看到的东西。天然的因果链，不需要任何转场
- **景别跳变**：同一主体从全景直切特写（或反之）。**必须跳够两级**——全景切中景会像跳帧，全景切特写才成立
- **动作中切 ≫ 动作完成后切**。等动作做完再切，每次都会多出半秒的"空转"，累积起来就是"拖"

## 音桥（J-cut / L-cut）：硬切不生硬的省力办法

声音跨过切点：下一镜的声音提前进（J-cut）或上一镜的声音延后走（L-cut）。
不需要任何素材，只需在时间线上把音频边界拖出画面边界。
**分镜写了"无缝衔接"的地方，优先用音桥而不是加转场特效**（详见 `sound-design` 技能）。

## 转场：默认不用

**默认硬切。** 即梦生成的画面细节密度高，叠化/推拉这类转场会把两个镜头的细节糊在一起，
观感是"廉价"而不是"高级"。

只在这三种情况用转场：

1. **时间跳跃**（当天 → 三天后）：短叠化或白闪
2. **空间大跳**（室内 → 另一座城市）：可用一个快速的划变或黑场
3. **段落分隔**（一集内的章节感，动漫常用）：设计过的转场卡

- 转场时长 **不超过 0.5 秒**。再长就是在浪费观众的注意力
- **同场景内的镜头之间永远硬切**，没有例外
- 分镜「衔接」列写了 `转场·<类型>` 才加转场；写 `硬切`、`动接动`、`无缝衔接` 一律零转场直拼

## 与 `transition_in` 字段的对应

分镜「衔接」列 → shotlist 的 `transition_in` → 精剪时的实际处理，是一条完整链路：

| 「衔接」列写法 | 摄影译进提示词 | 精剪的处理 |
|---|---|---|
| `定场` | 该镜自身建立空间 | 硬切；常是本场第一镜 |
| `动接动（承接 shNN 起身）` | 本镜起幅衔接上镜动作 | 硬切在动作中点 |
| `景别跳变` | 保持主体一致、景别拉开 | 硬切 |
| `视线引导` | 上镜末尾视线朝向、本镜给出对象 | 硬切 |
| `无缝衔接` | 首帧接上镜尾帧（常配 `first_from_prev`） | 零转场直拼，可加音桥 |
| `转场·叠化` / `转场·白闪` | — | 时间线上加转场，≤0.5 秒 |

**审片人按 `transition_in` 查执行**：写了动接动结果两个镜头动作对不上，属回炉项。

## 节奏曲线：一集不该是匀速的

平均镜长是均值，**真正的节奏是变化**：

- **开场**：最短的镜头放这里。短剧前 3 秒、段子第 1 秒，用最快的切建立信息密度
- **中段铺垫**：镜长逐步放长，给信息落地的时间。这里全用快切会让观众疲劳且记不住
- **反转/梗点前**：**故意拉长一拍**（一个 4–6 秒的静止或缓慢镜头）。这个"停顿"是冲击力的来源——
  没有铺垫的反转不叫反转，叫突兀
- **反转瞬间**：最短的一切。硬切，配重音
- **收尾**：段子结尾反转后**立刻结束**（1 秒内），短剧结尾留钩子镜 2–3 秒

## BGM 卡点

BGM 有重拍时，**把切点对到重拍上**，节奏感立刻成立。做法：

- 精剪时先把 BGM 铺上，看波形找重拍，再微调切点（±3 帧以内的移动不会影响内容）
- **只卡关键切点**（开场、反转、结尾），全片每个切点都卡会变成 MV，剧情反而被节奏压过去
- 卡不上就不卡。**为了卡点去改镜头长度是本末倒置**——镜头是花积分生成的，改不了

## 粗剪自查（`/edit` 输出后怎么看）

粗剪预览不是成片，它唯一的作用是**验证节奏假设**。看的时候只问三件事：

1. **前 3 秒（段子前 1 秒）抓住我了吗？** 没有 → 回 `/storyboard` 重排开场，不是加特效
2. **有没有哪一段我想快进？** 有 → 那一段镜长过长或信息重复，砍镜或缩短
3. **反转点有冲击吗？** 没有 → 检查反转前有没有那个"拉长一拍"的铺垫镜

**别在粗剪阶段纠结画质、字幕、配乐**——那些都是 `/finalcut` 的事。

## 交付自检

导演交付分镜表、剪辑师交付粗剪时，逐条过：

- [ ] 平均镜长落在该形态的基准区间内（不是每镜都 4 秒）
- [ ] 开场黄金时间（短剧 3 秒 / 段子 1 秒）内有冲突、悬念或反常
- [ ] 连续戏用了 8–15 秒长镜 + 时间码多节拍，而不是拆成一串 4 秒短镜
- [ ] 每个镜头的「衔接」列都写了，且写法在上表的对应关系内
- [ ] 反转点/梗点**前面**有一个拉长的铺垫镜
- [ ] 转场只出现在时间跳跃、空间大跳、段落分隔三种情况，且 ≤0.5 秒
- [ ] 同场景内的镜头之间全是硬切
