# /storyboard 分镜

## 运行时适配（跨 Agent 兼容）

- **支持 subagent 的运行时**（Claude Code / Hermes Agent 等）：按下文"调度 xxx agent"正常派发子代理执行
- **不支持 subagent 的运行时**（OpenClaw 等，以插件 bundle 方式安装）：正文提到"调度 X agent"时，
  改为读取插件根 `agents/<X>.md`（本技能目录上两级），以其为工作规范在当前上下文直接执行，效果等同
- **用户确认处**：有 AskUserQuestion 工具就用；没有则直接在对话中提问并等待用户回复，门禁语义不变


## 前置检查

- project.json 的 status.script 必须是 approved；否则告知用户先走 /script 定稿

## 流程

1. 调度 **director** agent：读定稿剧本，产出 `02-storyboard/ep{NN}-storyboard.md`
   （台词/音效列逐条沿用剧本的 `【对白】/【独白】` 标签，动漫等才用 `【旁白】`；内心独白镜头不必怼脸，可配空镜/反应/长镜）
2. 检查导演的时长核算：各镜头时长之和 vs 每集目标时长，偏差 >15% 让导演调整
3. **切镜自查（防"单镜头幻灯片"）**：统计分镜表——节拍总数 ÷ 镜头行数 ≥ 2、单节拍短镜（≤6s）占比 ≤ 40%、
   每行"衔接"列已填；任一不达标退回导演合并多节拍长镜/补衔接思路
4. 把分镜表和风险镜头提示呈现给用户；分镜不设硬门禁，用户无异议即自动推进
5. 更新 project.json：status.storyboard → done
6. 提取分镜表中的"出场角色"和"场景"去重清单，作为 /design 阶段的工作清单写在分镜文件末尾
7. **提取导演标了 `【白模】` 的镜号清单**（复杂运镜/精确空间/走位/一镜到底的镜头），同样写在分镜文件末尾，
   作为 `/previz` 白模预演阶段的候选清单
8. 提示下一步：有 `【白模】` 镜头 → 建议先走 `/previz`（可选阶段，Blender 本地渲白模锁运镜，**不耗即梦积分**），
   再走 `/design`；没有则直接 `/design`
